# retech-price-predictor

> Estimation du prix juste de revente pour ordinateurs portables reconditionnés au profit d'associations solidaires.

## Objectif
Pipeline Data / ML complet : ingestion web, persistance SQL, analyse exploratoire, prédiction de prix via Machine Learning et exposition API FastAPI.

## Structure
- `data/` : Jeux de données locaux (ignorés par git)
- `src/` : Modules métier (ingestion, processing, models, api)
- `notebooks/` : Analyses exploratoires (EDA)
- `tests/` : Tests unitaires et intégration
